# User Stories - Smart Clinic Management System

## Admin User Stories
* **As an Admin**, I want to be able to add, update, or remove doctor profiles, so that the clinic's staff directory remains accurate and up-to-date.
* **As an Admin**, I want to manage system access and assign user roles, so that only authorized personnel can access sensitive medical data or administrative functions.
* **As an Admin**, I want to view a dashboard summarizing daily clinic operations (e.g., total appointments, active doctors), so that I can effectively monitor and manage the clinic's workflow.

## Patient User Stories
* **As a Patient**, I want to browse a list of available doctors and filter them by specialty, so that I can find the right professional for my healthcare needs.
* **As a Patient**, I want to view a doctor's available time slots and book an appointment, so that I can secure a consultation at a convenient time.
* **As a Patient**, I want to view a history of my upcoming and past appointments, so that I can keep track of my medical visits.
* **As a Patient**, I want to be able to cancel or reschedule an existing appointment, so that I can adjust my plans if an emergency arises without calling the clinic.
* **As a Patient**, I want to access my medical records and view prescriptions given by doctors, so that I can easily follow my treatment plans.

## Doctor User Stories
* **As a Doctor**, I want to configure and manage my weekly availability and working hours, so that patients only book appointments when I am actually available.
* **As a Doctor**, I want to view my daily appointment schedule, so that I know exactly which patients I am seeing throughout the day.
* **As a Doctor**, I want to be able to access a patient's past medical history and records before or during a consultation, so that I can provide informed and accurate medical care.
* **As a Doctor**, I want to write, save, and attach prescriptions to a patient's record after a consultation, so that they have a permanent and secure record of their required medications.
